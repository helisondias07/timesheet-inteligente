# Limitações

- Demo, não apontamento oficial.
- Sem sync, sem multiplayer, sem histórico após F5.
- Sem calendário de feriados ou expediente.
- Sem parser de mensagem de commit para chaves de tarefa.
- Limites 12h/item e 24h/dia são regras explícitas deste rascunho, não política de um cliente.
- Playwright precisa de Chromium instalado no ambiente (`npx playwright install chromium`).
- Não há deploy. Não há nome oficial de repositório.
- Uso real por Helison Dias **não está confirmado** (formato de apontamento desconhecido).
